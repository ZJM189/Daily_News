# AI 热点信息每日汇总系统低保真原型图

版本：v0.2

日期：2026-09-01

关联文档：

- [需求说明书](requirements-specification.md)
- [业务流程图](business-flow.md)

说明：本文档为低保真文字原型，用于确认页面信息架构、主要组件和核心交互。视觉设计、组件库和响应式细节在 UI 设计阶段进一步细化。

## 1. 页面清单

首期 Web 看板包含以下页面：

- 登录页。
- 今日简报页。
- 历史简报页。
- 信息库页。
- 我的关注页。
- 详情抽屉。
- 来源管理页。
- 任务日志页。
- LLM Provider 设置页。
- 用户管理页。

MVP 不单独提供“热点专题”一级页面。专题聚合作为今日简报、历史简报和详情抽屉中的展示能力。

## 2. 全局布局

```text
+--------------------------------------------------------------------------------+
| Logo / Daily News                         全局搜索               用户菜单       |
+----------------------+---------------------------------------------------------+
| 侧边导航             | 主内容区                                                |
|                      |                                                         |
| - 今日简报           | 当前页面标题 / 页面操作                                 |

| - 信息库             | 全量检索 / 表格 / 详情抽屉                              |
| - 我的关注           | 关注规则 / 屏蔽规则 / 保存搜索 / 反馈记录               |
| - 来源管理(admin)    |                                                         |
| - 任务日志(admin)    |                                                         |
| - LLM 设置(admin)    |                                                         |

+----------------------+---------------------------------------------------------+
```

权限说明：

- 普通用户看到今日简报、历史简报、信息库、我的关注。
- 管理员额外看到来源管理、任务日志、LLM 设置、用户管理。
- 普通用户不能添加自定义外部 URL 信息源，也不能发起任意外部平台实时检索。

- 热点专题不作为独立页面，专题聚合信息在详情抽屉中展示。

## 7. 信息库页

```text
+--------------------------------------------------------------------------------+
| 信息库                                                            [保存搜索]    |
+--------------------------------------------------------------------------------+
| 搜索 [RAG____________] 来源 [全部 v] 来源类型 [全部 v] 分类 [全部 v]            |
| 状态 [全部 v] 时间 [最近 7 天 v] 排序 [score v]                                  |
+--------------------------------------------------------------------------------+
| 标题                         来源       分类       状态        score  发布时间  |
| -------------------------------------------------------------------------------- |
| 标题 A                       GitHub     开源项目   summarized  86     09:12     |
| 标题 B                       arXiv      论文研究   ranked      72     08:34     |
| 标题 C                       RSS        大厂动态   failed      61     08:10     |
+--------------------------------------------------------------------------------+
| 分页: < 1 2 3 ... >                                                              |
+--------------------------------------------------------------------------------+
```

核心交互：

- 搜索和筛选所有已采集入库内容。
- 点击行打开详情抽屉。
- 管理员可对单条重新摘要。
- 用户可将当前站内搜索保存为关注规则。
- 信息库不直接触发外部平台实时检索。

说明：

- 信息库是全量检索入口。
- 历史简报是按天归档的精选 digest。

## 8. 我的关注页

```text
+--------------------------------------------------------------------------------+
| 我的关注                                                                         |
+--------------------------------------------------------------------------------+
| 关注规则                                                                         |
| 关注关键词: [ Agent ] [ RAG ] [ Claude Code ] [ OpenAI ]        [+ 添加关键词]  |
| 关注分类:   [x] 模型与大厂  [x] 开源项目  [x] 论文研究  [ ] 行业与融资          |
| 来源类型:   [x] RSS [x] HN [x] GitHub [x] arXiv [ ] Product Hunt [x] HF         |
+--------------------------------------------------------------------------------+
| 屏蔽规则                                                                         |
| 排除关键词: [ 课程 ] [ 招聘 ] [ 广告 ]                         [+ 添加排除词]   |
| 屏蔽来源:   [ example.com ] [ 某低质量来源 ]                    [+ 添加来源]     |
+--------------------------------------------------------------------------------+
| 保存的搜索                                                                       |
| RAG 技术动态        query=RAG, 来源=GitHub+arXiv, 时间=最近7天       编辑/删除   |
| Claude Code 讨论    query=Claude Code, 来源=HN+RSS                  编辑/删除   |
+--------------------------------------------------------------------------------+
| 反馈记录                                                                         |
| 多看类似: Agent, RAG, GitHub                                                     |
| 少看类似: 融资, 营销                                                             |
+--------------------------------------------------------------------------------+
| [保存设置]                                                                       |
+--------------------------------------------------------------------------------+
```

核心交互：

- 关注关键词用于软加权。
- 排除关键词用于硬过滤。
- 关注分类用于我的关注视图默认筛选，并参与轻量排序加权。
- 关注来源类型用于我的关注视图默认筛选。
- 关闭来源类型用于硬过滤。
- 屏蔽来源用于硬过滤。
- 保存搜索把信息库中的站内搜索条件保存为关注规则。
- 多看类似和少看类似影响当前用户的个性化排序。
- 普通用户不能在这里添加外部 URL 信息源。

## 13. 空状态和错误状态

今日简报无内容：

```text
+--------------------------------------------------------------+
| 今天还没有生成简报                                             |
| 管理员可以手动触发采集和生成，系统也会按计划自动生成。           |
| [触发采集] [生成 Digest]                                       |
+--------------------------------------------------------------+
```

信息库无搜索结果：

```text
+--------------------------------------------------------------+
| 没有找到匹配内容                                               |
| 当前搜索只覆盖系统已采集入库的信息，不会触发外部实时检索。        |
+--------------------------------------------------------------+
```

任务失败：

```text
+--------------------------------------------------------------+
| 任务执行失败                                                   |
| 错误摘要: LLM provider timeout                                 |
| [查看详情] [重跑任务]                                          |
+--------------------------------------------------------------+
```

未授权：

```text
+--------------------------------------------------------------+
| 无权访问                                                       |
| 当前账号没有访问该管理功能的权限。                              |
+--------------------------------------------------------------+
```
