## 1. 页面清单

首期 Web 看板包含以下页面和访问壳层：

- 公开今日简报入口（`/`、未登录时的 `/today`）。
- 登录页。
- 今日简报页。
- 历史简报页。
- 信息库页。
- 我的关注页。
- 详情抽屉。
- 来源管理页。
- 任务日志页。
- LLM Provider 设置页。
- 用户管理页。

MVP 不单独提供“热点专题”一级页面。专题聚合作为今日简报、历史简报和详情抽屉中的展示能力。

## 2. 访问边界与全局布局

### 2.1 访问边界

```text
公开访问
├── /             今日简报公开入口
├── /today        今日简报只读页
└── /login        登录页

登录后
├── /today        今日简报
├── /history      历史简报
├── /library      信息库
├── /following    我的关注
└── /favorites    我的收藏

管理员
└── /admin/*      来源、任务、LLM、用户管理
```

权限原则：

- 未登录用户只读访问当天已发布的今日简报。
- 公开页面不调用收藏、关注、信息库聊天和管理接口。
- 登录成功后进入今日简报工作区。
- 未登录访问登录后页面时，跳转登录页并保留原目标路径。
- 普通用户访问 `/admin/*` 时显示无权状态，管理员才能进入后台。

权限说明：

- 普通用户看到今日简报、历史简报、信息库、我的关注。
- 管理员额外看到来源管理、任务日志、LLM 设置、用户管理。
- 桌面端侧边栏支持折叠成图标导航；移动端通过菜单按钮打开抽屉。
- 普通用户不能添加自定义外部 URL 信息源，也不能发起任意外部平台实时检索。
- 中间内容区统一为后台看板组件：页面标题、筛选卡片、指标卡、内容卡片、表格卡片、提示状态和分页栏。
- 阅读页采用卡片流展示；管理页采用表单卡片加表格卡片展示。
- 公开壳层不显示侧边栏和用户信息区；登录后才显示。

## 7. 信息库页

```text
+--------------------------------------------------------------------------------+
| 信息库                                             [保存当前搜索] [刷新]         |
+--------------------------------------------------------------------------------+
| 搜索 [RAG____________] 分类 [全部 v] 来源类型 [全部 v] 排序 [score v]           |
| 最低分 [____] 摘要状态 [全部 v]                                      [检索][重置] |
+--------------------------------------------------------------------------------+
| 数据洞察                                  入库总数/摘要覆盖/来源数/平均分 [展开] |
| 展开后：数据大屏 [最近30天 v] [收起]                                            |
| 最近入库趋势 | 来源类型分布 | 分类分布 | 分数分布 | 具体来源 Top                |
+--------------------------------------------------------------------------------+
| 结果列表                                      | 详情面板                       |
| 标题 / 摘要 / 分类 / 来源 / 分数 / 日期        | 摘要 / 重要性 / 标签 / 原文     |
+--------------------------------------------------------------------------------+
| 共 3,248 条  每页 [20 v]  首页 上一页 1 2 3 ... 下一页 末页  跳转[__]页[确定] |
+--------------------------------------------------------------------------------+
```

核心交互：

- 搜索和筛选所有已采集入库内容。
- 数据概览跟随当前筛选和统计窗口动态刷新。
- 数据概览默认折叠，点击后下拉展示完整数据大屏。
- 点击来源类型、分类或分数分布项后，反向更新筛选条件并重新检索。
- 分页支持每页 10、20、50、100 条；切换后回到第 1 页。
- 点击行打开详情抽屉。
- 管理员可对单条重新摘要。
- 用户可将当前站内搜索保存为关注规则。
- 信息库不直接触发外部平台实时检索。

说明：

- 信息库是全量检索入口。
- 历史简报是按天归档的精选 digest。

```text
+--------------------------------------------------------------------------------+
| 我的关注                                                                         |
+--------------------------------------------------------------------------------+
| 关注规则                                                                         |
| 关注关键词: [ Agent ] [ RAG ] [ Claude Code ] [ OpenAI ]        [+ 添加关键词]  |

| 来源类型:   [x] RSS [x] HN [x] GitHub [x] arXiv [ ] Product Hunt [x] HF         |
+--------------------------------------------------------------------------------+
| 屏蔽规则                                                                         |
| 排除关键词: [ 课程 ] [ 招聘 ] [ 广告 ]                         [+ 添加排除词]   |
| 屏蔽来源:   [ example.com ] [ 某低质量来源 ]                    [+ 添加来源]     |
+--------------------------------------------------------------------------------+
| 保存的搜索                                                                       |
| RAG 技术动态        query=RAG, 来源=GitHub+arXiv, 时间=最近7天       编辑/删除   |
| Claude Code 讨论    query=Claude Code, 来源=HN+RSS                  编辑/删除   |
+--------------------------------------------------------------------------------+
| 反馈记录                                                                         |
| 多看类似: Agent, RAG, GitHub                                                     |
| 少看类似: 融资, 营销                                                             |
+--------------------------------------------------------------------------------+
| [保存设置]                                                                       |
+--------------------------------------------------------------------------------+
```

核心交互：

- 关注关键词用于软加权。
- 排除关键词用于硬过滤。
- 关注分类用于我的关注视图默认筛选，并参与轻量排序加权。
- 关注来源类型用于我的关注视图默认筛选。
- 关闭来源类型用于硬过滤。
- 屏蔽来源用于硬过滤。
- 保存搜索把信息库中的站内搜索条件保存为关注规则。
- 多看类似和少看类似影响当前用户的个性化排序。
- 普通用户不能在这里添加外部 URL 信息源。
