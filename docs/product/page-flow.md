# AI 热点信息每日汇总系统页面流程

版本：v0.2

日期：2026-09-01

阶段：产品设计

关联文档：

- [PRD](prd.md)
- [产品原型](product-prototype.md)

## 1. 页面地图

```mermaid
flowchart TD
    Login[登录页] --> Today[今日简报]
    Today --> Detail[详情抽屉]
    History[历史简报] --> Detail
    Library[信息库] --> Detail
    Library --> SaveSearch[保存搜索弹窗]
    SaveSearch --> Following[我的关注]
    Today --> Following
    Following --> Today
    AdminSources[来源管理] --> SourceModal[新增/编辑来源弹窗]
    AdminJobs[任务日志] --> JobDetail[任务详情]
    AdminLLM[LLM 设置] --> LLMModal[新增/编辑 Provider 弹窗]
    AdminUsers[用户管理] --> UserModal[新增/编辑用户弹窗]
```

## 2. 登录与访问流程

```mermaid
flowchart TD
    A[访问站点] --> B{是否已登录}
    B -- 是 --> C[今日简报]
    B -- 否 --> D[登录页]
    D --> E[输入账号密码]
    E --> F{认证成功}
    F -- 是 --> C
    F -- 否 --> G[展示错误提示]
    G --> D
    C --> H{用户角色}
    H -- 普通用户 --> I[展示普通用户导航]
    H -- 管理员 --> J[展示普通用户导航和管理员导航]
```

## 3. 今日简报浏览流程

```mermaid
flowchart TD
    A[进入今日简报] --> B[默认展示系统精选]
    B --> C{切换视图}
    C -- 系统精选 --> D[按全局 score 展示]
    C -- 我的关注 --> E[应用用户规则计算 user score]
    D --> F[浏览今日概览/重点专题/最新信息流]
    E --> F
    F --> G{用户操作}
    G -- 查看详情 --> H[打开详情抽屉]
    G -- 打开原文 --> I[跳转外部原文]
    G -- 多看类似 --> J[记录正向反馈]
    G -- 少看类似 --> K[记录负向反馈]
    G -- 屏蔽来源 --> L[二次确认后屏蔽来源]
    H --> F
    J --> E
    K --> E
    L --> E
```

## 4. 信息库搜索与保存搜索流程

```mermaid
flowchart TD
    A[进入信息库] --> B[输入关键词]
    B --> C[选择来源/来源类型/分类/状态/时间范围]
    C --> D[检索已采集入库内容]
    D --> E{是否有结果}
    E -- 是 --> F[展示结果列表]
    E -- 否 --> G[展示站内无结果空状态]
    F --> H{用户操作}
    H -- 查看详情 --> I[打开详情抽屉]
    H -- 保存搜索 --> J[打开保存搜索弹窗]
    J --> K[输入规则名称]
    K --> L{是否为站内检索条件}
    L -- 是 --> M[保存到我的关注]
    L -- 否 --> N[拒绝保存外部 URL 或实时检索条件]
    M --> O[在我的关注页展示该规则]
```

## 5. 我的关注配置流程

```mermaid
flowchart TD
    A[进入我的关注] --> B[编辑关注关键词]
    B --> C[编辑排除关键词]
    C --> D[选择关注分类]
    D --> E[选择关注来源类型]
    E --> F[编辑屏蔽来源]
    F --> G[查看保存搜索]
    G --> H[查看反馈记录]
    H --> I[保存设置]
    I --> J[应用排除关键词/屏蔽来源/关闭来源类型硬过滤]
    J --> K[应用关注分类/来源类型默认筛选]
    K --> L[应用关注关键词/分类/反馈软加权]
    L --> M[规则应用到当前用户的我的关注视图]
```

## 6. 详情抽屉流程

```mermaid
flowchart TD
    A[从简报/历史/信息库点击详情] --> B[打开详情抽屉]
    B --> C{是否属于 topic}
    C -- 是 --> D[展示专题摘要/相关来源/事件时间线]
    C -- 否 --> E[展示单条内容详情]
    D --> F{摘要状态}
    E --> F
    F -- 成功 --> G[展示中文摘要和为什么重要]
    F -- 失败 --> H[展示失败状态和原始摘要兜底]
    G --> I[打开原文或提交反馈]
    H --> I
```

## 7. 管理员来源管理流程

```mermaid
flowchart TD
    A[管理员进入来源管理] --> B{操作}
    B -- 新增 --> C[打开新增来源弹窗]
    B -- 编辑 --> D[打开编辑来源弹窗]
    B -- 启用/禁用 --> E[更新来源状态]
    B -- 手动抓取 --> F[触发单 source 抓取]
    C --> G[保存配置]
    D --> G
    G --> H[更新来源列表]
    F --> I{抓取成功}
    I -- 是 --> J[更新最近抓取时间]
    I -- 否 --> K[显示最近错误]
```

## 8. 管理员任务流程

```mermaid
flowchart TD
    A[管理员进入任务日志] --> B[筛选任务]
    B --> C[查看任务列表]
    C --> D{任务状态}
    D -- 成功 --> E[查看详情]
    D -- 失败 --> F[查看错误详情]
    F --> G{是否重跑}
    G -- 是 --> H[创建新的任务记录]
    H --> I[执行任务]
    I --> J[刷新任务状态]
    G -- 否 --> C
```

## 9. 管理员配置 LLM 流程

```mermaid
flowchart TD
    A[管理员进入 LLM 设置] --> B{操作}
    B -- 新增 --> C[填写 provider 配置]
    B -- 编辑 --> D[修改 provider 配置]
    B -- 测试 --> E[调用测试连接]
    B -- 设置默认 --> F[更新默认 provider]
    C --> G[保存]
    D --> G
    E --> H{测试成功}
    H -- 是 --> I[显示可用]
    H -- 否 --> J[显示错误原因]
```

## 10. 管理员用户管理流程

```mermaid
flowchart TD
    A[管理员进入用户管理] --> B{操作}
    B -- 新增用户 --> C[填写邮箱/用户名/初始密码/角色]
    B -- 编辑角色 --> D[修改用户角色]
    B -- 启用/禁用 --> E[修改用户状态]
    B -- 重置密码 --> F[设置新密码]
    C --> G[保存并加密密码]
    D --> H[更新用户信息]
    E --> H
    F --> H
    G --> H
    H --> I[刷新用户列表]
```
