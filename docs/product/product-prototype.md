## 1. 原型范围

本原型描述首期 Web 看板的信息架构、页面布局、核心组件、页面状态和关键交互。该文档在需求阶段低保真原型基础上细化产品交互，但仍不包含视觉设计规范和前端组件实现细节。

## 2. 导航结构

```text
普通用户
├── 今日简报
├── 历史简报
├── 信息库
└── 我的关注

管理员
├── 今日简报
├── 历史简报
├── 信息库
├── 我的关注
├── 来源管理
├── 任务日志
├── LLM 设置
└── 用户管理
```

热点专题不作为独立一级导航。专题聚合信息放在今日简报/历史简报的专题卡片和详情抽屉中。

## 3. 全局框架

```text
+--------------------------------------------------------------------------------+
| shadcn 风格侧边栏：Logo / 分组导航 / 图标 / 折叠按钮 / 底部用户区              |
+--------------------------+-----------------------------------------------------+
| 主工作区                 | 顶部栏：移动端菜单 / 用户信息 / 退出                 |
|  图标 今日简报           | 页面标题                                             |
|  图标 历史简报           | 主要操作区                                           |
|  图标 信息库             | 筛选区                                               |
|  图标 我的关注           | 内容区                                               |
| 系统管理(admin)          |                                                     |
|  图标 来源管理           |                                                     |
|  图标 任务日志           |                                                     |
|  图标 LLM 设置           |                                                     |
|  图标 用户管理           |                                                     |
+----------------------+---------------------------------------------------------+
```

全局交互：

- 侧边栏按 shadcn/ui Sidebar 的分组、Header、Footer 和折叠模式设计。
- 桌面端支持展开/折叠，折叠后保留图标导航。
- 移动端通过顶部菜单按钮打开抽屉式侧边栏。
- 底部用户区展示当前用户和角色，顶部栏保留退出登录。
- 普通用户不展示 admin 导航项。
- 主内容区采用统一后台组件体系：PageHeader、SurfaceCard、MetricCard、Notice、TableCard、PaginationBar。
- 内容消费页使用“标题区 + 指标/摘要 + 内容卡片流”的结构。
- 管理页使用“表单卡片 + 数据表卡片”的结构，避免每页散写原生表格和表单。
- 表格型页面优先复用 TanStack Table；图表型页面优先复用 ECharts。

## 7. 信息库页

```text
+--------------------------------------------------------------------------------+
| 信息库                                            [保存当前搜索] [刷新]          |
+--------------------------------------------------------------------------------+
| PageHeader：标题 / 说明 / 页面级操作                                             |
+--------------------------------------------------------------------------------+
| SurfaceCard：筛选检索                                                            |
| 搜索 [RAG____________] 分类 [全部 v] 来源类型 [全部 v] 排序 [score v]           |
| 最低分 [____] 摘要状态 [全部 v]                                      [检索][重置] |
+--------------------------------------------------------------------------------+
| 数据洞察                                  入库总数/摘要覆盖/来源数/平均分 [展开] |
+--------------------------------------------------------------------------------+
| 展开后：数据大屏                              [最近7天 v] [收起数据大屏]        |
| 指标卡：入库总数 / 已摘要 / 来源数 / 平均分                                    |
| 最近入库趋势：ECharts 柱线组合图                                             |
| 来源类型分布：ECharts 环形图，点击可筛选                                       |
| 分类分布：ECharts 横向柱状图，点击可筛选                                       |
| 分数分布：ECharts 分桶柱状图                                                  |
| 具体来源 Top 12：按 source.name 动态统计                                      |
+--------------------------------------------------------------------------------+
| 左侧结果列表                                  | 右侧详情面板                    |
| 标题 A / 摘要 / 分类 来源 分数 日期             | 标题、摘要、重要性、来源、标签   |
| 标题 B / 摘要 / 分类 来源 分数 日期             | [查看原文]                       |
+--------------------------------------------------------------------------------+
| 共 3,248 条  每页 [20 v]  首页 上一页 1 2 3 ... 下一页 末页  跳转[__]页[确定] |
+--------------------------------------------------------------------------------+
```

交互：

- 搜索仅查询已采集内容。
- 数据概览跟随当前检索条件动态刷新。
- 数据概览默认折叠为洞察入口，点击后下拉展开完整数据大屏。
- 图表使用 Apache ECharts 渲染，后端返回动态维度数组，前端不写死来源名称。
- 时间范围支持最近 7 天、最近 30 天和全部。
- 点击来源类型、分类或分数分布项，可反向写入筛选条件并重新检索。
- 分页支持每页 10、20、50、100 条；切换每页数量后回到第 1 页。
- 保存当前搜索将站内检索条件保存为我的关注规则。
- 点击行打开详情抽屉。
- 管理员在失败/已摘要条目上看到“重新摘要”操作。

规则：

- 保存搜索只能保存信息库当前站内检索条件。
- 保存搜索不允许输入外部 URL。
- 保存后参与我的关注流排序和过滤。

空状态：

```text
没有找到匹配内容
当前搜索只覆盖系统已采集入库的信息，不会触发外部实时检索。
```

## 8. 我的关注页

```text
+--------------------------------------------------------------------------------+
| 我的关注                                                                         |
+--------------------------------------------------------------------------------+
| 关注规则                                                                         |
| 关注关键词 [Agent] [RAG] [Claude Code] [OpenAI]                  [+ 添加]       |
| 关注分类   [x] 模型与大厂  [x] 开源项目  [x] 论文研究  [ ] 行业与融资           |
| 来源类型   [x] RSS [x] HN [x] GitHub [x] arXiv [ ] Product Hunt [x] HF          |
+--------------------------------------------------------------------------------+
| 屏蔽规则                                                                         |
| 排除关键词 [课程] [招聘] [广告]                                  [+ 添加]       |
| 屏蔽来源   [example.com] [低质量来源]                            [+ 添加]       |
+--------------------------------------------------------------------------------+
| 保存的搜索                                                                       |
| RAG 技术动态      GitHub+arXiv / 最近7天                         [编辑][删除]   |
| Claude Code 讨论  HN+RSS / 最近30天                              [编辑][删除]   |
+--------------------------------------------------------------------------------+
| 反馈记录                                                                         |
| 多看类似: Agent, RAG, GitHub                                                     |
| 少看类似: 融资, 营销                                                             |
+--------------------------------------------------------------------------------+
| [保存设置]                                                                       |
+--------------------------------------------------------------------------------+
```

交互：

- 关注关键词属于软加权。
- 关注分类在我的关注视图中作为默认筛选，并参与轻量排序加权。
- 关注来源类型在我的关注视图中作为默认筛选。
- 排除关键词/屏蔽来源属于硬过滤。
- 关闭来源类型在我的关注视图中作为硬过滤。
- 保存搜索规则来自信息库，不发起外部抓取。
- 删除反馈后，该反馈不再影响排序。

## 11. 任务日志页

```text
+--------------------------------------------------------------------------------+
| 任务日志                                  [一键生成今日简报] [刷新]              |
+--------------------------------------------------------------------------------+
| 任务总数 84 | 本页等待 0 | 本页运行 1 | 本页异常 2                          |
+--------------------------------------------------------------------------------+
| TanStack Table：任务 / 状态 / 处理数量 / 进度 / 创建时间 / 耗时 / 说明错误       |
| 抓取内容  system·1001       成功      120/120    100%   09/05 08:00   120s  -    |
| 生成中文摘要 manual·1002    失败      19/20      95%    09/05 08:03   34s  展开 |
+--------------------------------------------------------------------------------+
```

交互：

- 仅管理员可访问。
- 失败任务可以查看错误详情。
- 表格使用 TanStack Table 驱动列渲染和本页排序。
- 任务日志外层使用 PageHeader、MetricCard、SurfaceCard 和 TableCard 统一管理页视觉。
- 重跑会生成新的任务记录。
- 调度设置可修改 Digest 生成时间，默认 Asia/Shanghai 每天 08:00。

## 13. 用户管理页

```text
+--------------------------------------------------------------------------------+
| 用户管理                                                         [新增用户]      |
+--------------------------------------------------------------------------------+
| 角色 [全部 v] 状态 [全部 v] 关键词 [____________]                                |
+--------------------------------------------------------------------------------+
| 用户名/邮箱                 角色        状态        创建时间        操作          |
| admin@example.com           admin       启用        2026-09-01      编辑/重置密码 |

```

交互：

- 仅管理员可访问。

- 禁用用户后，该用户不能登录。
- 重置密码后旧密码失效。
