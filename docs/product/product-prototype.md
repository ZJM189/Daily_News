# AI 热点信息每日汇总系统产品原型

## 2026-09-09 增量：公开今日简报原型

未登录用户可以直接查看已发布的今日简报，不需要先登录。公开页面首期只提供概览阅读、精选条目卡片、原文跳转和登录入口；历史简报、信息库、我的关注、我的收藏、智能助手和管理能力仍需登录。登录后进入完整工作区，管理员额外看到系统管理导航。

## 2026-09-06 增量：收藏原型

主工作区在“我的关注”后新增“我的收藏”。桌面采用页内目录导航与收藏列表，详情使用右侧抽屉；手机端目录改为下拉选择。收藏弹窗包含根目录、自建目录、搜索和内联新建目录。完整线框与交互见 [我的收藏设计](favorites.md)，沿用现有本地 UI 组件与 lucide 图标。

## 1. 原型范围

本原型描述首期 Web 看板从公开访问到登录后工作区、管理员后台的完整信息架构、页面布局、核心组件、页面状态和关键交互。公开页面以内容消费为主，登录后页面以检索、个性化和管理为主。本文件仍是产品原型，不替代视觉设计规范和前端组件实现细节。

## 2. 导航结构

```text
未登录用户
└── 今日简报（/ 或 /today，只读）

普通用户
├── 今日简报
├── 历史简报
├── 信息库
├── 我的关注
└── 我的收藏

管理员
├── 今日简报
├── 历史简报
├── 信息库
├── 我的关注
├── 我的收藏
├── 来源管理
├── 任务日志
├── LLM 设置
└── 用户管理
```

热点专题不作为独立一级导航。专题聚合信息放在今日简报/历史简报的专题卡片和详情抽屉中。

## 3. 全局框架

### 3.1 页面与权限总览

| 路由 | 未登录 | 普通用户 | 管理员 | 页面职责 |
| --- | --- | --- | --- | --- |
| `/` | 可访问 | 进入今日简报 | 进入今日简报 | 公开入口/今日简报入口 |
| `/today` | 可访问，只读 | 可访问 | 可访问，可重新生成 | 查看当天已发布简报 |
| `/login` | 可访问 | 可访问 | 可访问 | 用户认证 |
| `/history` | 跳转登录 | 可访问 | 可访问 | 查看历史简报 |
| `/library` | 跳转登录 | 可访问 | 可访问，可重新摘要 | 全量信息库检索 |
| `/following` | 跳转登录 | 可访问 | 可访问 | 个性化关注流和规则 |
| `/favorites` | 跳转登录 | 可访问 | 可访问 | 用户私有收藏 |
| `/admin/*` | 跳转登录 | 无权访问 | 可访问 | 系统管理 |


公开页面规则：

- 只展示 `published` 状态且日期为当天的 digest。
- 展示完整的已发布条目，不展示未入选信息库内容、用户偏好和管理数据。
- 条目以只读卡片展示摘要、来源、分数和原文入口；公开详情抽屉作为后续增强。
- 隐藏收藏、关注反馈、屏蔽来源、信息库智能助手和重新生成操作。
- 顶部保留登录入口；登录成功后进入 `/today`，不回到公开壳层。
- 移动端保留顶部品牌、日期、登录按钮，内容改为单列。

### 3.3 登录后工作区框架

```text
+--------------------------------------------------------------------------------+
| shadcn 风格侧边栏：Logo / 分组导航 / 折叠按钮 / 底部用户区                    |
+--------------------------+-----------------------------------------------------+
| 主工作区                 | 顶部栏：移动端菜单 / 用户信息 / 退出                 |
|  图标 今日简报           | 页面标题                                             |
|  图标 历史简报           | 主要操作区                                           |
|  图标 信息库             | 筛选区                                               |
|  图标 我的关注           | 内容区                                               |
| 系统管理(admin)          |                                                     |
|  图标 来源管理           |                                                     |
|  图标 任务日志           |                                                     |
|  图标 LLM 设置           |                                                     |
|  图标 用户管理           |                                                     |
+----------------------+---------------------------------------------------------+
```

全局交互：

- 侧边栏按 shadcn/ui Sidebar 的分组、Header、Footer 和折叠模式设计。
- 桌面端支持展开/折叠，折叠后保留图标导航。
- 移动端通过顶部菜单按钮打开抽屉式侧边栏。
- 底部用户区展示当前用户和角色，顶部栏保留退出登录。
- 普通用户不展示 admin 导航项。
- 主内容区采用统一后台组件体系：PageHeader、SurfaceCard、MetricCard、Notice、TableCard、PaginationBar。
- 内容消费页使用“标题区 + 指标/摘要 + 内容卡片流”的结构。
- 管理页使用“表单卡片 + 数据表卡片”的结构，避免每页散写原生表格和表单。
- 表格型页面优先复用 TanStack Table；图表型页面优先复用 ECharts。
- `FavoritesProvider` 和信息库智能助手只在登录后挂载，公开页面不请求私有接口。
- 未登录访问私有路由时跳转 `/login?next=<原路径>`；普通用户访问管理路由显示无权状态。

### 3.4 页面状态统一约定

每个页面都需要覆盖以下状态：

| 状态 | 页面表现 |
| --- | --- |
| 首次加载 | 保留页面结构，内容区显示轻量加载状态 |
| 空数据 | 说明当前范围没有内容，并给出下一步入口 |
| 请求失败 | 展示可理解的错误信息和重试操作 |
| 无权限 | 说明需要登录或管理员权限，不泄露接口细节 |
| 已完成操作 | 使用页面内成功提示或 toast，不阻塞继续阅读 |
| 移动端 | 不出现横向滚动；表格转为纵向条目或可横向滑动的局部区域 |

```text
+--------------------------------------------------------------------------------+
| 信息库                                            [保存当前搜索] [刷新]          |
+--------------------------------------------------------------------------------+
| PageHeader：标题 / 说明 / 页面级操作                                             |
+--------------------------------------------------------------------------------+
| SurfaceCard：筛选检索                                                            |
| 搜索 [RAG____________] 分类 [全部 v] 来源类型 [全部 v] 排序 [score v]           |
| 最低分 [____] 摘要状态 [全部 v]                                      [检索][重置] |
+--------------------------------------------------------------------------------+
| 数据洞察                                  入库总数/摘要覆盖/来源数/平均分 [展开] |
+--------------------------------------------------------------------------------+
| 展开后：数据大屏                              [最近7天 v] [收起数据大屏]        |
| 指标卡：入库总数 / 已摘要 / 来源数 / 平均分                                    |
| 最近入库趋势：ECharts 柱线组合图                                             |
| 来源类型分布：ECharts 环形图，点击可筛选                                       |
| 分类分布：ECharts 横向柱状图，点击可筛选                                       |
| 分数分布：ECharts 分桶柱状图                                                  |
| 具体来源 Top 12：按 source.name 动态统计                                      |
+--------------------------------------------------------------------------------+
| 左侧结果列表                                  | 右侧详情面板                    |
| 标题 A / 摘要 / 分类 来源 分数 日期             | 标题、摘要、重要性、来源、标签   |
| 标题 B / 摘要 / 分类 来源 分数 日期             | [查看原文]                       |
+--------------------------------------------------------------------------------+
| 共 3,248 条  每页 [20 v]  首页 上一页 1 2 3 ... 下一页 末页  跳转[__]页[确定] |
+--------------------------------------------------------------------------------+
```

交互：

- 搜索仅查询已采集内容。
- 数据概览跟随当前检索条件动态刷新。
- 数据概览默认折叠为洞察入口，点击后下拉展开完整数据大屏。
- 图表使用 Apache ECharts 渲染，后端返回动态维度数组，前端不写死来源名称。
- 时间范围支持最近 7 天、最近 30 天和全部。
- 点击来源类型、分类或分数分布项，可反向写入筛选条件并重新检索。
- 分页支持每页 10、20、50、100 条；切换每页数量后回到第 1 页。
- 保存当前搜索将站内检索条件保存为我的关注规则。
- 点击行打开详情抽屉。
- 管理员在失败/已摘要条目上看到“重新摘要”操作。

规则：

- 保存搜索只能保存信息库当前站内检索条件。
- 保存搜索不允许输入外部 URL。
- 保存后参与我的关注流排序和过滤。

空状态：

```text
没有找到匹配内容
当前搜索只覆盖系统已采集入库的信息，不会触发外部实时检索。
```

## 7.1 全局信息库悬浮聊天助手

```text
桌面端：

+--------------------------------------------------------------+
| 任意已登录主页面                                             |
|                                                              |
|                         +--------------------------------+   |
|                         | 信息库助手        [+] [关闭]   |   |
|                         | 最近7天RAG论文                  |   |
|                         | [历史会话] [GitHub Agent...]   |   |
|                         |                                |   |
|                         | 你：最近 7 天 RAG 论文         |   |
|                         | 助手：共找到 12 条，先展示 6 条 |   |
|                         | [结果卡片][结果卡片][查看全部] |   |
|                         |                                |   |
|                         | 输入查询...              [发送] |   |
|                         +--------------------------------+   |
+--------------------------------------------------------------+

移动端：

+--------------------------------------+
| 任意已登录主页面                     |
|                                      |
|                                      |
| +----------------------------------+ |
| | 信息库助手          [+] [关闭]   | |
| | 消息历史                         | |
| | 输入查询...              [发送] | |
| +----------------------------------+ |
+--------------------------------------+
```

交互：

- 默认收起为右下角悬浮按钮。
- 展开后加载最近会话和消息历史，支持新建会话和切换最近会话。
- 提交自然语言后先执行意图门控，范围外问题返回固定拒答。
- 范围内问题由默认 LLM Provider + DeepAgents 解析意图，并通过 SSE 展示状态、回答文本、筛选 chips 和最多 6 条结果预览。
- 点击“查看全部”跳转到信息库并回填筛选条件。
- 空状态明确提示“仅搜索系统已采集入库内容，不会触发外部实时检索”。
- LLM 不可用时显示“智能解析暂不可用，已按关键词检索”，并继续展示站内结果。
- 登录页不展示悬浮聊天助手。

- 任务日志外层使用 PageHeader、MetricCard、SurfaceCard 和 TableCard 统一管理页视觉。
- 重跑会生成新的任务记录。
- 调度设置可修改 Digest 生成时间，默认 Asia/Shanghai 每天 08:00。

## 14. 公开今日简报开发拆分

| 模块 | 功能需求 | 关键约束 |
| --- | --- | --- |
| 后端 digest 接口 | `GET /api/v1/digests/today` 支持匿名读取当天已发布 digest | 只返回发布态；历史 digest 仍需登录 |
| 前端访问壳层 | `/`、`/today`、`/login` 作为公开路由，其余路由需要登录 | 公开路由不挂载收藏 provider 和智能助手 |
| 公开首页 | `/` 直接展示今日简报，不再展示工作台介绍页 | 顶部只有品牌、今日简报入口和登录按钮 |
| 今日简报页 | 未登录只读；登录后显示完整工作区能力 | 登录态可见收藏、关注、智能助手和角色导航 |
| 登录页 | 支持 `next` 参数，登录后回到原目标私有页面 | 无 `next` 时默认进入 `/today` |
| 管理权限 | `/admin/*` 继续依赖管理员角色 | 未登录返回登录；普通用户显示无权 |
| 测试 | 覆盖匿名今日简报、私有路由跳转、管理员权限和移动端无横向溢出 | 匿名页面不得请求收藏/聊天接口 |
