日期：2026-09-01

阶段：产品设计

关联文档：

- [PRD](prd.md)
- [页面流程](page-flow.md)

## 1. 原型范围

本原型描述首期 Web 看板的信息架构、页面布局、核心组件、页面状态和关键交互。该文档在需求阶段低保真原型基础上细化产品交互，但仍不包含视觉设计规范和前端组件实现细节。

## 2. 导航结构

```text
普通用户
├── 今日简报
├── 历史简报
├── 信息库
└── 我的关注

管理员
├── 今日简报
├── 历史简报
├── 信息库
├── 我的关注
├── 来源管理
├── 任务日志
├── LLM 设置
└── 用户管理
```

热点专题不作为独立一级导航。专题聚合信息放在今日简报/历史简报的专题卡片和详情抽屉中。

## 3. 全局框架

```text
+--------------------------------------------------------------------------------+
| Daily News                          全局搜索                      用户菜单      |
+----------------------+---------------------------------------------------------+
| 今日简报             | 页面标题                                                |
| 历史简报             | 主要操作区                                              |
| 信息库               | 筛选区                                                  |
| 我的关注             | 内容区                                                  |
| -------------------- |                                                         |
| 来源管理(admin)      |                                                         |
| 任务日志(admin)      |                                                         |
| LLM 设置(admin)      |                                                         |
| 用户管理(admin)      |                                                         |
+----------------------+---------------------------------------------------------+
```

全局交互：

- 点击全局搜索进入信息库，并带入关键词。
- 用户菜单提供当前用户信息和退出登录。
- 普通用户不展示 admin 导航项。

## 5. 今日简报页

```text
+--------------------------------------------------------------------------------+
| 今日简报                                      日期 2026-09-01   [重新生成]*admin |
+--------------------------------------------------------------------------------+
| 视图 [系统精选] [我的关注]                                                       |
| 状态 已发布 | 专题 8 | 条目 24 | 来源 48 | 最后生成 08:00                       |
+--------------------------------------------------------------------------------+
| 今日概览                                                                         |
| 今天 AI 热点集中在模型更新、Agent 工具、开源项目和多模态论文。                   |
+--------------------------------------------------------------------------------+
| 今日重点专题                                                                     |
| [92] OpenAI 发布新模型                                                           |
| 模型与大厂动态 | 来源 5 | 首次出现 09:10 | 最近更新 11:30                      |
| 中文专题摘要                                                                     |
| 为什么重要                                                                       |
| [详情] [原文] [多看类似] [少看类似] [屏蔽来源]                                  |
+--------------------------------------------------------------------------------+
| 分类 tabs: 全部 / 模型与大厂 / 开源项目 / 论文研究 / 产品发布 / 社区讨论         |
+--------------------------------------------------------------------------------+
| 最新信息流                                                                       |
| [83] 标题                                      RSS       10:21      [详情][原文] |
|      中文摘要预览                                                                |
| [76] 标题                                      arXiv     09:42      [详情][原文] |
|      中文摘要预览                                                                |
+--------------------------------------------------------------------------------+
```

交互：

- 系统精选：按全局 score 展示。
- 我的关注：应用当前用户硬过滤和软加权。
- 分类 tab 只改变当前页展示，不改变用户偏好。
- 多看类似/少看类似记录反馈并提示“已更新你的关注偏好”。
- 屏蔽来源需要二次确认。
- 管理员重新生成 digest 后刷新状态。

## 7. 信息库页

```text
+--------------------------------------------------------------------------------+
| 信息库                                                           [保存搜索]     |
+--------------------------------------------------------------------------------+
| 搜索 [RAG____________] 来源 [全部 v] 来源类型 [全部 v] 分类 [全部 v]            |
| 状态 [全部 v] 时间 [最近 7 天 v] 排序 [score v]                                  |
+--------------------------------------------------------------------------------+
| 标题                         来源       分类       状态        score  发布时间  |
| -------------------------------------------------------------------------------- |
| 标题 A                       GitHub     开源项目   summarized  86     09:12     |
| 标题 B                       arXiv      论文研究   ranked      72     08:34     |
| 标题 C                       RSS        大厂动态   failed      61     08:10     |
+--------------------------------------------------------------------------------+
| < 1 2 3 ... >                                                                    |
+--------------------------------------------------------------------------------+
```

交互：

- 搜索仅查询已采集内容。
- 保存搜索打开弹窗，让用户填写规则名称。
- 点击行打开详情抽屉。
- 管理员在失败/已摘要条目上看到“重新摘要”操作。

保存搜索弹窗：

```text
+--------------------------------------------------------------+
| 保存搜索                                             [关闭]   |
+--------------------------------------------------------------+
| 规则名称     [RAG 技术动态____________________]              |
| 当前条件     关键词 RAG / GitHub+arXiv / 最近 7 天 / score   |
| 应用位置     [x] 我的关注视图默认筛选                         |
|              [x] 参与个性化排序加权                           |
|                                                              |
| [取消] [保存]                                                |
+--------------------------------------------------------------+
```

规则：

- 保存搜索只能保存信息库当前站内检索条件。
- 保存搜索不允许输入外部 URL。
- 保存后在我的关注页“保存的搜索”区域展示。

空状态：

```text
没有找到匹配内容
当前搜索只覆盖系统已采集入库的信息，不会触发外部实时检索。
```

## 8. 我的关注页

```text
+--------------------------------------------------------------------------------+
| 我的关注                                                                         |
+--------------------------------------------------------------------------------+
| 关注规则                                                                         |
| 关注关键词 [Agent] [RAG] [Claude Code] [OpenAI]                  [+ 添加]       |
| 关注分类   [x] 模型与大厂  [x] 开源项目  [x] 论文研究  [ ] 行业与融资           |
| 来源类型   [x] RSS [x] HN [x] GitHub [x] arXiv [ ] Product Hunt [x] HF          |
+--------------------------------------------------------------------------------+
| 屏蔽规则                                                                         |
| 排除关键词 [课程] [招聘] [广告]                                  [+ 添加]       |
| 屏蔽来源   [example.com] [低质量来源]                            [+ 添加]       |
+--------------------------------------------------------------------------------+
| 保存的搜索                                                                       |
| RAG 技术动态      GitHub+arXiv / 最近7天                         [编辑][删除]   |
| Claude Code 讨论  HN+RSS / 最近30天                              [编辑][删除]   |
+--------------------------------------------------------------------------------+
| 反馈记录                                                                         |
| 多看类似: Agent, RAG, GitHub                                                     |
| 少看类似: 融资, 营销                                                             |
+--------------------------------------------------------------------------------+
| [保存设置]                                                                       |
+--------------------------------------------------------------------------------+
```

交互：

- 关注关键词属于软加权。
- 关注分类在我的关注视图中作为默认筛选，并参与轻量排序加权。
- 关注来源类型在我的关注视图中作为默认筛选。
- 排除关键词/屏蔽来源属于硬过滤。
- 关闭来源类型在我的关注视图中作为硬过滤。
- 保存搜索规则来自信息库，不发起外部抓取。
- 删除反馈后，该反馈不再影响排序。

|                                                              |

| - 相关来源                                                   |

|                                                              |

交互：

- 摘要失败时显示处理状态和原始摘要。

+--------------------------------------------------------------------------------+

## 11. 任务日志页

```text
+--------------------------------------------------------------------------------+
| 任务日志                                  [触发采集] [生成 Digest] [调度设置]   |
+--------------------------------------------------------------------------------+
| 类型 [全部 v] 状态 [全部 v] 日期 [2026-09-01 v]                                  |
+--------------------------------------------------------------------------------+
| 任务ID   类型        状态       开始时间     耗时      错误摘要      操作         |
| 1001     collect     success    08:00        120s      -             详情         |
| 1002     summarize   failed     08:03        34s       provider err  重跑/详情    |
+--------------------------------------------------------------------------------+
```

交互：

- 仅管理员可访问。
- 失败任务可以查看错误详情。
- 重跑会生成新的任务记录。
- 调度设置可修改 Digest 生成时间，默认 Asia/Shanghai 每天 08:00。

## 12. LLM 设置页

```text
+--------------------------------------------------------------------------------+
| LLM Provider 设置                                             [新增 Provider]    |
+--------------------------------------------------------------------------------+
| 默认 Provider [OpenAI Compatible v]                                             |
+--------------------------------------------------------------------------------+
| 名称        类型                  模型              状态       操作              |
| OpenAI      OpenAI-compatible     gpt-4.1-mini      启用       测试/编辑          |
| DeepSeek    OpenAI-compatible     deepseek-chat     启用       测试/编辑          |
+--------------------------------------------------------------------------------+
```

交互：

- API key 输入后不回显明文。
- 测试连接成功/失败均显示反馈。
- 禁用默认 provider 前需要先选择新的默认 provider。

## 13. 用户管理页

```text
+--------------------------------------------------------------------------------+
| 用户管理                                                         [新增用户]      |
+--------------------------------------------------------------------------------+
| 角色 [全部 v] 状态 [全部 v] 关键词 [____________]                                |
+--------------------------------------------------------------------------------+
| 用户名/邮箱                 角色        状态        创建时间        操作          |
| admin@example.com           admin       启用        2026-09-01      编辑/重置密码 |
| user@example.com            user        启用        2026-09-01      编辑/重置密码 |
+--------------------------------------------------------------------------------+
```

交互：

- 仅管理员可访问。
- 新增用户需要邮箱/用户名、初始密码、角色和启用状态。
- 禁用用户后，该用户不能登录。
- 重置密码后旧密码失效。
