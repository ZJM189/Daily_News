# 我的收藏

日期：2026-09-06

## 首期范围

收藏是用户主动保存的信息条目，独立于关注规则。入口覆盖信息库列表、信息库详情和我的关注流；简报展示聚合专题，首期不提供专题收藏。

采用单层目录，一条收藏属于根目录或一个自建目录。“全部收藏”汇总全部内容，“根目录”表示未归类内容。个人备注、标签、导出和多级子目录暂不包含。

## 页面布局

```text
我的收藏                                               [刷新]
目录                      全部收藏 · N 条
全部收藏       N          搜索 / 分类 / 来源 / 排序 / 检索
根目录         N          --------------------------------
我的目录 [+]              标题、摘要、来源、分类、分数、发布时间
  Agent        N [...]    目录、收藏时间          [详情][原文][更多]
  论文         N [...]    ...
                          每页 10/20/50/100、页码与跳转
```

复用 PageScaffold、PageHeader、PaginationBar、现有色彩与间距、lucide 图标。目录与内容采用分隔布局，详情使用右侧抽屉；手机上目录改为下拉框，详情使用全屏抽屉。目录名和标题允许换行。

## 收藏交互

1. 未收藏显示空心书签；已收藏显示填充书签，提示所属目录。
2. 无自建目录时直接存根目录，成功后可撤销。
3. 有目录时弹窗默认选根目录，支持搜索目录及内联创建；创建成功选中新目录，确认后才收藏。取消收藏弹窗不会新增收藏，但已明确创建的目录保留。
4. 已收藏按钮打开管理弹窗，可选择其他目录或根目录、取消收藏。
5. 写操作期间禁用重复提交；失败保留弹窗选择并允许重试，不显示成功状态。
6. 列表和详情共享收藏状态，页面切换及窗口重新获得焦点时刷新。每页批量查询状态，不逐条请求。

## 目录与检索

- 目录支持创建、重命名、删除。名称 1 到 80 字符，去首尾空格后不能为空，同一用户下名称唯一。
- 根目录和全部收藏始终存在，不可改名或删除。
- 删除自建目录前确认，提示其中收藏数量；所有收藏原子地移至根目录。
- 切换目录或筛选回到第一页；最后一页内容移除后自动回到有效页。
- 搜索与筛选只作用于当前目录范围；支持收藏时间、发布时间及分数排序。
- 空目录显示“暂无收藏”；筛选无结果提供“清除筛选”；请求失败提供重试。

## 隐私与数据规则

收藏和目录按登录用户隔离，管理员没有例外。收藏不改变采集、评分、推荐及简报。重复操作不会产生重复收藏；移动不重置收藏时间。收藏展示原条目的最新摘要和分数，取消收藏不删除原条目。

## 验收

- 无目录直存根目录，有目录选择后保存。
- 新建目录后自动选中，取消收藏操作不会新增收藏。
- 同名目录报错，目录删除后收藏仍可在根目录找到。
- 信息库列表和详情书签同步，关注流与收藏页状态一致。
- 列表筛选、排序、分页正确，移动和取消后计数刷新。
- 普通用户及管理员都无法读取或修改他人的收藏目录。
- 桌面、手机无水平溢出，弹窗可用键盘操作，保存失败保留输入。
